# MM-Dia
This is the official repository of the ICLR 2026 paper "From Natural Alignment to Conditional Controllability in Multimodal Dialogue".

For details of the dataset and Multimodal Dialogue Generation tasks, please refer to our [Paper](https://openreview.net/forum?id=fBagP6w6yE) and [Demo Page](https://mmdiaiclr26.github.io/mmdiaiclr26/)
